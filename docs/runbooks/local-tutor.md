# Try the local tutor

From the repository root with Node 22:

```powershell
npm ci --ignore-scripts
npm run dev:tutor
```

Open `http://127.0.0.1:4173`. Stop with Ctrl+C; restart after source edits. The server
builds the browser bundle in memory and listens on loopback only. No account, provider,
telemetry or external request is used. This is a local development preview, not a release;
no release manifest or hosted artifact is produced.

Select a square and enter a value using the keypad or keys 1–9. Toggle **Notes** for pencil
marks; **Clear** removes the selected value or its notes. **Undo** restores the previous move.
Arrow keys move between squares; Delete/Backspace clears a focused square.

**Get help** opens a non-modal sheet. Start with a nudge, request a stronger hint, then an
explanation. Naked-single explanations reveal one existing clue at a time, highlight it in
amber, and slash the ruled-out digit in a separate teaching strip. Earlier references stay
softly highlighted. Givens are never crossed out. Pause, Show all and Smaller hint control
the story; reduced-motion users receive the complete explanation immediately. The player
places the answer. Close or Escape dismisses the sheet and returns focus to Get help.

Any accepted board change cancels the current lesson. Incorrect entries are marked and help
requests recovery with Clear or Undo before teaching. Correctness here uses the unique puzzle's
completion derived by verified singles, including errors that do not cause immediate duplicates.
Notes never affect candidates. Reload resets everything; there is no saving or puzzle picker.

## Evidence and limits

The fixture is generated by `scripts/local-tutor-fixture.mjs` using existing
`classic-symmetric` 1.0.0, seed `vsc-fixture/v1:2`: the first qualifying attempt, 28 givens,
53 verified placements. Regenerate with `node scripts/local-tutor-fixture.mjs --write` after
compilation. Tests reproduce selection and independently check uniqueness with exact cover.
This local fixture is not `showcase-v1` and has no private collision-clearance claim.

`npm run test:tutor` checks fixture regeneration, immutable lesson facts and a Chromium
playthrough to completion, including recovery, stale-story cancellation, notes/undo, keyboard,
reduced motion, local-only requests and widths 320/390/1024. Packed consumers exercise lesson
exports in Node and Chromium. These checks are not accessibility certification or learning
outcomes; no frozen coaching eval exists before this first deterministic renderer.

The [accepted local plan](../product/plans/VSC-PLAN-2026-09-05.3.md) and
[saved interaction concept](../product/concepts/coach-interaction.md) define the scope and design
reference. Implemented runtime surfaces are `apps/replay-web` and `packages/coach-core`;
`localLesson` accepts an authentic state-bound single capability and returns frozen text/cell
beats, or null for stale/forged input. It never places a value or constructs a proof. Existing
wire schemas are unchanged. Only naked/hidden singles are supported; no live AI, automatic
interventions, elimination techniques, private integration or production deployment is included.
