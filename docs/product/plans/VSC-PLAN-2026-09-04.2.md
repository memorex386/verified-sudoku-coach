# Verified Sudoku Coach portable AI engineering foundation

This accepted amendment extends
[VSC-PLAN-2026-09-03.1](VSC-PLAN-2026-09-03.1.md) with the maintainer's
2026-09-04 decision that product inference and engineering automation must be agent- and
provider-neutral by contract. The completed public-foundation package remains governed by the
earlier plan; all unstarted packages use this version.

## Decision

Keep deterministic Sudoku authority, workflow policy, permissions, validation, and evidence in
vendor-neutral repository contracts. OpenAI remains the first reference inference adapter, while
Claude, Gemini, and open-weight runtimes can join through narrow, versioned, capability-declaring
adapters that pass the same conformance and evaluation gates. The reviewer cohort uses one frozen
approved provider; alternate providers remain owner/evaluation-only until separately accepted.

Repository instructions and Agent Skills are canonical. Product-specific agent entrypoints, model
APIs, hooks, schedulers, notifications, source-control operations, and deployment systems are leaf
adapters. An adapter cannot weaken proof, privacy, budget, authorization, or release policy, and no
provider/model substitution is silent.

Insert a portability-foundation package before product contracts freeze, then continue the
renumbered ten-package sequence in the generated [registry](../../work-packages/). Add a bounded
dependency-PR steward as a separately gated automation: deterministic classification first,
strictly limited model escalation, one repair, exact-SHA validation, and terminal defer/escalate
outcomes. Production release remains a separate authority with a human gate during the evidence
phase and at most one verified rollback when later implemented.

## Governing public form

The [interoperability architecture](../../architecture/interoperability.md), accepted ADRs,
[automation contracts](../../contracts/agent-automation.md), acceptance catalog, and work packages
own the enforceable detail. The earlier plan remains an immutable record of the foundation already
accepted; this record owns the changed sequencing and portability decision.

## Sanitization boundary

This amendment contains no provider credential, private repository source, participant data,
production trace, model response, assistant transcript, hidden reasoning, or unreviewed external
agent instruction.
