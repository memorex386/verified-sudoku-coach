# Verified Sudoku Coach public AI engineering foundation

This is the sanitized public decision record for the plan accepted by the maintainer on
2026-09-03. It lets a new contributor resolve the `accepted_plan` value in every work package
without relying on a private conversation.

## Decision

Build a reusable Apache-2.0 coaching core in this repository while Sudoku World remains private
and consumes immutable releases through narrow adapters. Deterministic code is the only authority
for Sudoku facts; provider output is untrusted teaching input that must reference verified values.

Deliver the work in the nine ordered work packages in the generated
[registry](../../work-packages/). Accept the public foundation before feature implementation, then
implement contracts/proofs, coaching, provider/evaluation, replay, private integration, pilot, and
career evidence in that order. Merge, publication, deployment, spend, and participant exposure
remain separate human-authorized actions.

## Governing public form

The [product charter](../charter.md) owns product scope and claims. The
[architecture principles](../../architecture/principles.md), accepted
[ADRs](../../decisions/), [privacy policy](../../privacy.md), and
[acceptance catalog](../../acceptance/catalog.md) own the detailed constraints. Work packages own
current delivery state and evidence. This record identifies the accepted plan version; it does not
duplicate those authorities.

## Sanitization boundary

This record contains no private Sudoku World source, infrastructure identifiers, credentials,
production boards, participant data, model responses, agent conversations, or hidden reasoning.
The private repository keeps its own integration authority and may expose only reviewed aggregate
or immutable-release evidence here.
