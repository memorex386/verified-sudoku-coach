This is the ADR registry. Accepted ADRs define durable technical choices; Proposed, Superseded, and
Rejected entries remain visible as decision history. Supersede rather than silently rewriting a
decision whose context or consequences materially changed.

change requires updating this index and affected work packages/contracts. Start new decisions from
the [ADR template](template.md); example values are not project state.
