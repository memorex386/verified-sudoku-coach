# Release evidence

The [foundation workflow record](workflows/WF-2026-001-foundation.md) summarizes AI-assisted roles,
human-owned decisions, failures found, and validation without exposing transcripts or private
reasoning. The [portable control-plane workflow record](workflows/WF-2026-002-portability.md)
records the provider/agent boundary and bounded dependency-controller work without claiming a live
automation service. No release evidence exists during WP-2026-001 or WP-2026-002. Future immutable
release directories will contain a machine-readable manifest and generated human summary binding
source, dependencies, contracts, runtime-AI behavior, fixtures, aggregate evals, demo artifacts,
security/license checks, CI, and known limitations. Raw provider output and production data are
never release evidence.
